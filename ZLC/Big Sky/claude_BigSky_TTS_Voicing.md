# Big Sky Voicing for Text-to-Speech

The owner listens to drill responses via text-to-speech. **TTS reads exactly what is written.** Table is WRITTEN identifier → spoken form. Where no spoken form is listed, write and speak as-is.

Same contract as `../S56/claude_S56_TTS_Voicing.md`. Callsign digit grouping, registration spelling and "zero, never oh" live in `claude_US_Carrier_Callsigns.md` (copied at `../_shared/`).

## Radio name and sectors

Radio name **"Big Sky Approach"** (departures: "Big Sky Departure"), BOI SOP 3-1-1. Sector names (Sage, Alpine, Bozeman) are English words, spoken as written. Callsigns are `BOI_G_APP`, `BOI_A_APP`, `BZN_APP`; speak the letters as letters. Mountain Home's radio names ("X-Ray North", "Cowboy Control") are a different facility.

## Pronunciations — UNSPECIFIED

No identifier below has an owner-supplied pronunciation. Write it as-is; **do not invent a phonetic spelling**.

### Boise STARs and fixes

`KOURT`, `SPUUD`, `SADYL`, `JIMMI`, `BEWTE`, `TOILS`, and `KYANN` / `KYAAN`. The BOI SOP and the BOI-ZLC LOA both spell it `KYANN`; CIFP codes it `KYAAN4`. This is an as-written anomaly, preserved. Speak whichever is on the page, as-is.

### Bozeman and Boise SIDs

`BGSKY`, `BOBKT`, `MEADO`, `HIA`, `BOI3`, `GOWEN`, `BZN6` and the other procedure names in `claude_BigSky_CIFP_Procedures.md`. All **unspecified**. A procedure name ends in its revision number; write it as-is.

### Bozeman STARs

`BGMAN`, `EATZZ`, `LOSST`, `POWDA`, `SUBKY`. **Unspecified.**

### Named airspace

`Ellis Corridor` is English and is spoken as written.

## Runways

Expanded: `10L` → "one zero left", `28R` → "two eight right", `12` → "one two", `30` → "three zero". Boise's `10L/R` is "one zero left and right". Never "thirty".

## Frequencies

Digit by digit with "point": `119.600` → "one one nine point six zero zero". `118.975` → "one one eight point nine seven five". Never "one nineteen".

## What to do when a pronunciation is missing

Write the identifier as-is, and add the row here when the owner supplies it.
