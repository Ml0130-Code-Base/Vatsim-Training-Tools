Training toolset

Seven drill decks, three air route traffic control centers, one honest account of what each one knows.

Single-file training tools for one controller working toward certification at several facilities. Every operational number traces to a document and a paragraph, and every gap is rendered rather than hidden.

Read this before you fly anything here

Only M98 has been flown. Everything else is a skeleton, and the word is load-bearing: the frame is real and cited, the geometry is mostly not carried, and each tool renders the difference rather than papering over it.

A tool that does not carry sector boundaries does not claim a boundary was crossed. Where a check is weaker than it looks, the tool says so on the page. Read the “what this tool knows” registry inside each one before trusting a number in a drill.

These are study aids built by a trainee, not facility training material and not endorsed by any virtual air route traffic control center. The governing orders and letters of agreement always win.

Working offline

Every tool is one self-contained HTML file with no dependencies and no build step. Save the page and it keeps working with the machine offline — the web font is the only external reference, and each page is fully functional without it.

Progress is kept in your browser’s local storage, per tool, on the device you used. It does not follow you to another browser or another machine, and there is no server holding a copy. The Markdown or JSON export inside each tool is the real backup.

What this site publishes, and what it does not

This site carries the tools only. The facility source documents, the transcribed reference markdown, the gap analyses and the session logs stay in the repository and are not published here.

Sector geometry in the Salt Lake, Big Sky, Chicago and Kalamazoo tools comes from the VATGlasses datasets for ZLC and ZAU, each managed by its own virtual air route traffic control center — vatglasses.uk, licensed CC BY-NC-SA 4.0. Second-tier data: the facility orders win over it, and an owner-supplied boundary supersedes it.

Aeronautical data here is for flight simulation on the VATSIM network. Not for real-world navigation.
