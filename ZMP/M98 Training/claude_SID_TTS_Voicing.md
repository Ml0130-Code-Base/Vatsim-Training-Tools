Michael listens to drill responses via text-to-speech. TTS reads exactly what is written, so write SID names in their SPOKEN form so they are pronounced correctly. Table is WRITTEN identifier -> spoken form. If no spoken form is listed, write/speak as-is.

- WLSTN -> Wellstone
- COULT -> Coult (as-is)
- ZMBRO -> Zum-bro
- RST -> Rochester
- ORSKY -> OR-SKEE
- SCHEP -> Shepp
- KBREW -> Kay-Brew
- SMERF -> Smurf
- LEINY -> Liney

Use the spoken forms in radio transmissions and prose alike. Fixes (RUMLE, HRBEK, MCONL, etc.) not yet specified — write as-is until Michael provides pronunciations.
