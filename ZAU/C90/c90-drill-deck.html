Set the seat, build the drill, fly it, bank what it taught.

The Chicago TRACON frame — positions, combining, configurations, finals, capture points — carried out of the vZAU documents, and the facility footprint from the ZAU vARTCC's own sector data. The internal sectorisation and the procedure geometry are still not carried, and every empty slot says so and names the document that fills it.

Skeleton. Nothing here is invented: a number is either traced to a vZAU document by paragraph, or the slot is empty and marked empty. Student notes attach to any section, any table row and any empty slot, and export as Markdown to be folded back into the reference set.
Skeleton tool. Single file, no build step, no network, works from file://. Every operational number traces to the vZAU document set — see claude_Source_Documents_Index.md and claude_C90_Reference.md.

Facility footprint and field positions from the VATGlasses ZAU dataset, managed by ZAU vARTCC — vatglasses.uk, licensed CC BY-NC-SA 4.0. Second-tier data: the facility orders win over it, and an owner-supplied boundary supersedes it.
