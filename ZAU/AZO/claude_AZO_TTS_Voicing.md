# AZO Voicing for Text-to-Speech

The owner listens to drill responses via text-to-speech. **TTS reads exactly what is written.** Table is WRITTEN identifier → spoken form. Where no spoken form is listed, write and speak as-is.

Same contract as `../C90/claude_C90_TTS_Voicing.md`. Callsign digit grouping, registration spelling and "zero, never oh" live in `claude_US_Carrier_Callsigns.md` (copied at `../_shared/`).

## Sector names (SOP 2-2)

Sector names are English words and are spoken as written.

| Written | Spoken | Note |
|---|---|---|
| `GRIFFIN`, `BRONCO`, `BELLS`, `LUMBERTOWN`, `WHITECAP`, `SHORELINE` | as written | West Wall |
| `CAPITAL` / `Capitol` | as written | The documents spell it both ways; neither is corrected |
| `REYNOLDS`, `CHIPPEWA`, `OLDS`, `BUICK`, `BAY` | as written | East Wall |

Callsigns are `AZO_<letter>_APP`; speak the letter as a letter.

## Runways

Expanded: `8L` → "eight left", `26R` → "two six right", `35` → "three five". Never "thirty-five".

## Beacon codes

Digit by digit: `4500` → "four five zero zero". Never "forty-five hundred".

## Frequencies

Digit by digit with "point": `128.400` → "one two eight point four zero zero". `118.65` → "one one eight point six five".

## What to do when a pronunciation is missing

Write the identifier as-is, and add the row here when the owner supplies it.
